# Brasa Burger

Site demonstrativo de uma hamburgueria artesanal, criado com HTML, CSS e JavaScript puro.

## Arquivos

- `index.html` — estrutura e conteúdo da página.
- `style.css` — cores, layout, responsividade e estilos.
- `script.js` — menu mobile, filtros do cardápio, ano automático e interações simples.

## Como executar

1. Extraia a pasta `brasa-burger` para o computador.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou instale a extensão **Live Server** no VS Code e clique em **Go Live**.

Não é necessário instalar dependências nem usar Node.js.

## Personalização importante

- Troque as fotos pelos arquivos ou URLs de imagem que desejar.
- Edite os nomes, descrições e preços no `index.html`.
- Ajuste as cores no início de `style.css`, dentro de `:root`.
- Antes de publicar, substitua o número demonstrativo `5500000000000` no `script.js` e o link do botão do WhatsApp no `index.html`.
- Endereço, e-mail, preços e marca são fictícios para demonstração.

As fotos e fontes externas precisam de conexão com a internet para carregar.
